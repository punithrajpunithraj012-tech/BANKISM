# BANKISM Backend

Standalone Express/TypeScript backend for the BANKISM Blue-Team AI Banking Firewall and fraud intelligence platform.

## Run
1. Copy `.env.example` to `.env` and configure optional AI keys.
2. `npm install`
3. `npm run dev`
4. API is available at `http://localhost:3000/api/health`.

The frontend is intentionally separated and should run independently (default Vite port 5173).
